DrawMath — quick guide

Drawing

  • V Move/select · P Point · S Segment · L Line · R Ray
  • G Polygon · B Rectangle · N Regular polygon
  • C Circle · O 3-point circle · A Arc
  • M Midpoint · I Intersection · T Tangents · F Reflect
  • D Dimension (driving) · E Measure (reference)
  • New points snap to existing points, lines, circles and intersections and stay attached. Hold Alt to place freely.
  • Two-click tools also work as press-drag-release.

Navigation

  • Wheel = zoom · Right-drag, middle-drag or Space+drag = pan · Home = fit
  • Esc cancels the current tool, then returns to Move
  • Ctrl+Z/Ctrl+Shift+Z undo/redo · Del delete · Ctrl+A select all
  • H hide selection (it still constrains) · Shift+H show all · Show hidden draws hidden items faded so you can pick them

Constraints

  • Select objects (Shift+click or box-drag), then click a button in the constraint bar.
  • Dragging keeps every constraint satisfied; the status bar shows the remaining degrees of freedom.
  • Conflicting constraints are refused and rolled back.
  • Click a constraint icon on the canvas (or in the list) to select it, then Del to remove it.

Dimensions & variables

  • Double-click a dimension to type a value or an expression: 3.5, a, 2*a+1, sqrt(a^2+b^2), t/2.
  • Unknown names become sliders automatically. Drag a slider and the figure updates.
  • ▶ animates a slider (bounce / loop / once). Turn on Trace path on a point to draw its locus.
  • Angles are in degrees; trig functions use degrees too.
  • Reference (grey) measurements only display values; tick Driving to make them constrain.
